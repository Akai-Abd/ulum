# AGENTS.md — Project Instructions for AI Agents

## Mandatory Documentation Rule

Whenever you make any changes to this codebase (new features, bug fixes, CLI flags/commands, GUI controls, architecture, or releases):

1. **ALWAYS update `README.md`**:
   - Update version numbers, download links, and `.deb` filenames (e.g. in Quickstart).
   - Update the **Key Features** section to describe any new capabilities.
   - Update the **CLI Reference** table with any new commands or flags.
   - Update the **Desktop GUI** section to detail new UI buttons, badges, or dashboard workflows.
   - Update the test suite pass counts.

2. **ALWAYS update `Universal Linux Update Manager.md` (PRD)**:
   - Update **Document version** and **Status** at the top.
   - Update **Section 7 (Core product features)** with detailed specifications of new mechanisms.
   - Update **Section 8 (CLI command specification)** table with new commands and arguments.

3. **ALWAYS update `CHANGELOG.md`**:
   - Document all changes under the matching semantic version header.

**Never forget or skip updating these documentation files. This rule is permanent.**
